# استودیو آرکا

پروژه‌ی چندصفحه‌ای راست‌چین با React، Vite، Tailwind CSS و React Router.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه‌ی نهایی:

```bash
npm run build
npm run preview
```

## مسیرها

- `/` صفحه‌ی اصلی
- `/projects` آرشیو پروژه‌ها و فیلتر دسته‌بندی
- `/projects/:slug` الگوی پویا برای پنج پروژه
- `/contact` اطلاعات تماس و فرم پیام

## یادداشت‌ها

- منوی موبایل با بستن از طریق کلید گریز، بازگردانی فوکوس و محصورسازی پیمایش صفحه‌کلید کار می‌کند.
- برای جلوگیری از پوشیده‌شدن مقصد پیمایش، بخش‌های دارای شناسه فاصله‌ی بالایی پیمایش دارند.
- متون دوجهته، مسیر راهنما، شماره‌ها و شناسه‌های تماس با جداسازی راست‌به‌چپ/چپ‌به‌راست تنظیم شده‌اند.
- تصاویر دارای متن جایگزین و ابعاد صریح هستند؛ تصویر اصلی با اولویت بالا و سایر تصاویر با بارگذاری تنبل دریافت می‌شوند.

- تصاویر پوشه‌ی `public/images` جای‌نگهدارهای برداری هستند و هیچ چهره‌ی انسانی ندارند.
- فرم مشاوره فقط در وضعیت محلی React کار می‌کند و داده را در کنسول ثبت می‌کند؛ بک‌اندی متصل نیست.
- فونت متغیر وزیرمتن با پیش‌بارگذاری و `font-display: swap` از مخزن توزیع‌شده‌ی پروژه بارگیری می‌شود.
- نشانی دامنه و اطلاعات تماس در داده‌های نمونه قرار دارند و پیش از انتشار واقعی باید تأیید شوند.
